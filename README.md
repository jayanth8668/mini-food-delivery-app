# Mini Food Delivery App

This project is a small food delivery application built as part of a first-round assignment.
The focus is on clean architecture, simple UI, and proper state management.

## Tech Stack
- React Native (Bare CLI)
- TypeScript
- Zustand
- TanStack Query
- Mock REST API

## Features
- Restaurant list
- Restaurant menu screen
- Add and remove items from cart
- Cart summary and total price

## Setup Steps
1. Clone the repository
2. Install dependencies  
   npm install
3. Start Metro  
   npx react-native start
4. Run the app  
   npx react-native run-android

## Notes
The UI is kept minimal to focus on functionality and clean code.
